# BANGCHUL · 방출 2.0.1

생각만 하던 것을, 세상 밖으로.

글·그림·음악을 모으고 날짜별 진전을 남기는 창작 작업 공간입니다. 기존 Cinematic Black, 명조 헤드라인과 문밖으로 흐르는 연기를 유지합니다. 일반 UI는 Pretendard Variable 동적 서브셋을 사용합니다.

## 기능

- 기존 7장면 온보딩 안에서 글·그림·음악 분야 선택.
- 글: 긴 문단, 750ms 기기 자동 저장, 날짜별 원고, 읽기 전용 조회, 확인 후 복원. 복원 직전 원고는 별도 보호 백업으로 남기며 다시 조회·복원할 수 있습니다.
- 그림: JPG/PNG 원본 보관, 별도의 WebP 미리보기와 썸네일, 확대, 수정본과 이전 버전 조회.
- 음악: MP3 원본 보관, 기본 오디오 플레이어, 재생·정지·구간 이동, 버전 조회. 서버 파일은 HTTP Range를 지원합니다.
- 계정: 호스팅에서 제공하는 **ChatGPT 로그인**, 비공개 서버 저장과 다른 기기에서 불러오기. 구글·카카오 직접 로그인은 아직 연결하지 않았습니다.
- 브라우저 프로젝트를 비어 있는 계정에 복사한 후 다시 읽어 검증합니다. 브라우저 원본은 삭제하지 않습니다.
- 서버 저장 충돌 시 자동 덮어쓰기를 막고, 확인 후 기기 백업을 보호한 뒤 서버 기록을 다시 열 수 있습니다.
- 탭별 미전송 원고를 따로 보관합니다. 다시 접속하면 계정 메뉴에서 보호된 원고를 읽고 내려받거나 복구할 수 있습니다.
- 중단된 프로젝트 가져오기는 서버에 저장된 시작 당시의 계획을 기준으로 남은 파일부터 계속합니다.

**자동 공개, 공개 아카이브, 커뮤니티·댓글, 결제·판매·정산은 제공하지 않습니다.** 마감 이후에도 비공개입니다. 계정당 하나의 프로젝트를 지원하는 초기 버전입니다.

## 실행

Node.js 24 이상에서:

    npm ci
    npm run build
    npm run db:local

별도 터미널에서 각각 실행합니다:

    npm run dev:api

    npm run dev

Vite 주소를 엽니다. API는 127.0.0.1:8788로 연결됩니다. 로컬에서는 로그인을 가장하지 않고 계정 기능을 기본 차단합니다. 로그인 없이 글·그림·음악을 해당 브라우저에 저장할 수 있습니다. npm run preview는 프론트엔드 미리보기입니다. HTML 더블클릭 실행은 지원하지 않습니다.

## 저장과 보안

기존 bangchul:mvp:v1 키와 version: 1을 유지합니다. kind가 없는 구 프로젝트는 글로 열며 본문·설명·메모·일일 기록을 보존합니다. 로컬 파일은 별도 IndexedDB에 저장됩니다. 브라우저 사이트 데이터를 지우면 로컬 원본도 사라집니다.

계정 연결은 자동 이관이 아닙니다. 가져오기를 선택하고 확인해야 복사됩니다. 다른 프로젝트가 있는 계정에는 덮어쓰지 않습니다. JSON 백업은 원고·기록·파일 메타데이터를 포함하며 바이너리 원본은 따로 내려받습니다.

서버는 Workers + D1 + 비공개 R2입니다. Sites가 검증해 주입한 사용자 ID를 서버에서 확인하고, 모든 프로젝트·파일 조회에 소유자를 검사합니다. 공개 R2 URL과 익명 쓰기 API가 없습니다. API/파일 응답은 private, no-store; 정적 해시 자산은 장기 캐시합니다.

Sites 외부에 배포할 때 IDENTITY_PROVIDER=sites를 임의로 사용해서는 안 됩니다. 이 모드는 **Sites 신뢰 경계 안에서만** 유효합니다. 외부 배포는 실제 OAuth/세션 검증이 필요합니다. wrangler.local.jsonc는 인증을 기본 차단하며 실제 계정·버킷 ID나 비밀키를 담지 않습니다.

## 검사

    npm run typecheck
    npm test
    npm run build

63개 테스트에는 실제 로컬 D1/R2를 이용한 소유권·무인증 차단, 원본 바이트 보존, 동시 탭 원고 복구, 중단된 가져오기 재개, 업로드 완료 응답 유실, 중복·용량 한도, 손상 이미지 거부, Range/HEAD가 포함됩니다. 테스트는 임시 로컬 리소스만 사용합니다. 가상 원고·음원을 배포하지 않습니다.

## 배포와 운영

.openai/hosting.json의 기존 Site ID와 공개 범위를 유지합니다. dist/server/index.js Worker와 dist/client 프론트엔드를 함께 빌드합니다. drizzle/ SQL은 추가형 최초 마이그레이션이며 사용자 데이터 초기화·시드는 없습니다. 적용한 SQL/스냅샷은 수정하지 않고 후속 마이그레이션을 추가합니다.

개인 Cloudflare 계정의 요금제·청구 상태는 확인되지 않았습니다. 유료 플랜 전환, Images 유료 기능 활성화, 개인 계정의 유료 리소스 생성 명령은 실행하지 않았습니다. 현재 Sites 관리형 저장·게시 경로를 사용합니다. 서비스 한도는 전체 청구액을 보장하는 지출 상한은 아닙니다. 구체적인 한도와 공식 요금 출처는 [v2.0 보고서](docs/v2.0-release.md)에 있습니다.

wrangler.preview.jsonc는 계정/API 없이 프론트엔드만 확인하는 이전 정적 미리보기용입니다.
