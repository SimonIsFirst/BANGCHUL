# BANGCHUL MVP v1.1 · 2026-10-30

## 직접 비교

- [B · Cinematic Black](https://bangchul-v1-preview.simonjoker19.chatgpt.site/?design=cinematic&preview=1)

디자인 검토 전용입니다. 일반 프로젝트와 분리되어 기존 입력을 건드리지 않으며, 미리보기에서의 입력은 새로고침하면 사라집니다. 두 링크는 사이트의 기존 접근 권한을 그대로 따릅니다.

## 바꾼 것

1. 공개 약속이 바로 드러나는 메인 카피와 '첫 방출 시작하기'. 슬로건은 유지했습니다.
2. 이미지 없는 A와 기존 이미지/연기를 사용한 B. 모바일/데스크톱 텍스트 영역을 어둡게 보호하고 첫 화면의 연기를 낮췄습니다.
3. 이름 → 작품 → 설명 뒤, 작품명과 다음 단계를 보여주는 전면 전환. 입력 없이 바로 진행/뒤로 가기가 가능합니다. 카운터는 7장면에 맞췄습니다.
4. 첫 화면, 동의, 완료 화면에서 현재는 자동 공개되지 않는 로컬 체험임을 안내합니다.
5. 모바일 설명/날짜 입력은 16px, 축소 높이에서도 문서 스크롤을 유지합니다.

## 지킨 것

기존 React/TypeScript/Vite 구조, 데이터 키/버전/프로젝트 필드, 날짜와 유효성 검사, 기존 초안 단계 복원, 설명 수정/메모, 공개 전 동의, D-Day, 모션 끄기/축소 지원을 유지합니다. 실제 자동 공개·로그인·결제·커뮤니티는 추가하지 않았습니다. 브랜드는 BANGCHUL / 방출 그대로입니다. 배경 원본 파일도 변경하지 않았습니다.

## 검증 및 남은 확인

TypeScript/프로덕션 빌드와 테스트 17개 통과. 실제 브라우저에서 등록, 전환 새로고침, 뒤로 이동, 날짜 오류, 동의, 수정/기록 복원, 미리보기 데이터 분리, 390px/320px의 화면을 확인했습니다. 자세한 시나리오는 `verification.md`에 있습니다.

실제 휴대폰의 가상 키보드, OS 모션 축소 전환, 저사양 기기 성능은 별도 실기 확인이 필요합니다. A/B는 사용자 행동을 추적하는 실험이 아니라 수동 디자인 비교입니다. 다음 판단은 첫 화면의 카피 이해도와 등록 이탈 구간을 소수 사용자에게 확인하는 것입니다.

현재 사용하는 비공개 프리뷰에 반영하는 범위이며, 개인 Cloudflare 계정의 운영 도메인이나 접근 권한은 변경하지 않습니다.
