- 공백 이름 차단, 이름/작품 Enter 이동, 설명 예시 키보드 표시, 설명 뒤 전환과 뒤로 가기, 전환 장면 새로고침 복원 확인.
- 과거 날짜와 기간 역전 차단. 시작일 2026-11-02 + 14일 → 종료일 2026-11-16, 14 DAYS / D−17. 체크 전 생성 비활성화, 동의 후 생성 확인.
- 실제 로컬 체험에서 설명 수정/진행 기록을 추가하고 새로고침 복원 확인. A/B 검토에서 다른 이름을 입력한 뒤 일반 주소로 복귀해 기존 프로젝트와 기록이 유지됨을 확인.
- 1280px 데스크톱, 390×844 및 320×740 모바일에서 전환/날짜/동의/완료, 가로 넘침 없음 확인. 390×480 축소 높이에서 설명 필드가 보이고 입력 글자 16px임을 확인. 실제 휴대폰 가상 키보드 검증은 아닙니다.
- 해당 흐름의 콘솔 오류/경고 없음. OS 모션 축소 설정과 저사양 실기 성능은 직접 비교하지 않았습니다. 기존 지원 코드는 유지했습니다.

## 2026-10-18 문 밖 연기 애니메이션

- 데스크톱 및 390px 모바일에서 문턱 시작점, 바닥 방향의 흐름과 가로 넘침 없음 확인. 콘솔 오류/경고 없음.
- 원본 배경 사진과 기존 로컬 데이터 저장 방식은 유지. 운영체제 모션 축소 및 탭 비활성화 중지는 구현했으나 OS 설정 전환/탭 비활성화의 별도 실기 검증은 하지 않음.

- 실제 브라우저에서 공백 이름 차단, Enter 다음 이동, 입력 도중 새로고침 복원, 설명 예시 포커스, 과거 날짜/기간 역전 차단, 선택한 시작일 기준 14일 계산을 확인.
- 시작일 2026-10-22, 종료일 2026-11-05를 선택하면 14 DAYS / D−18, 프로젝트에는 시작 예정·비공개로 표시됨을 확인.
- 동의 체크 전 생성 비활성화, 체크 후 생성, 설명 수정/메모 추가 후 새로고침 복원, 초기화 Escape 취소와 확인 흐름을 재확인.

## 실제 브라우저

Codex 내장 브라우저에서 로컬 React 앱을 클릭하고 입력했습니다. 임의의 테스트 이름과 작품만 사용했습니다.

| 시나리오 | 확인 결과 |
| --- | --- |
| 최초 접속/CTA | 확정된 카피, 이미지 없는 첫 화면, 수동 CTA로 이름 화면 이동 |
| 이름/작품 이름 | 빈 값과 공백 입력에서 다음 비활성화, 오류 안내, Enter로 다음 이동 |
| 이전 화면 | 이름과 작품 이름 입력 유지 |
| 초안 새로고침 | 작품 이름 입력 중 새로고침 후 같은 단계와 값 복원 |
| 작품 설명 | 입력 가능, Enter는 줄바꿈이며 다음 화면으로 이동하지 않음 |
| 설명 예시 | `?` 버튼 키보드 포커스로 예시 표시 |
| 날짜 프리셋 | 7/14/30일과 D−7/D−14/D−30 일치 |
| 직접 날짜 | 2026-11-01 입력 후 요약·동의 화면·프로젝트에 같은 날짜와 D−21 표시 |
| 과거 날짜 | 2020-01-01 입력 시 오류 안내와 다음 비활성화 |
| 동의 | 체크하지 않으면 생성 불가, 체크 후 프로젝트 생성 |
| 프로젝트 복원 | 새로고침 후 창작자·작품·예정일 복원 |
| 설명 수정 | 설명 저장 후 새로고침에도 수정 내용 유지 |
| 진행 기록 | 메모 추가 후 기록에 표시, 새로고침 후 유지 |
| 초기화 취소 | 취소와 Escape에서 기존 프로젝트 유지, 초기화 버튼으로 포커스 복귀 |
| 초기화 확인 | 테스트 프로젝트 삭제 후 첫 화면, 새로고침 후에도 초기 상태 |
| 데스크톱 | 기본 뷰포트에서 첫 화면/온보딩/프로젝트 확인 |
| 모바일 | 390×844, 320×740에서 첫 화면·등록·프로젝트·초기화 확인, 가로 넘침 없음 |
| 콘솔 | 해당 테스트 흐름의 오류/경고 없음 |

테스트 중 직접 날짜 입력의 이벤트 반영 문제와 320px 화면의 가로 넘침을 발견하여 수정했고, 해당 시나리오를 다시 확인했습니다. 모바일 자동 입력 전체 등록 흐름은 약 18초였지만 실제 사용자의 읽기/작성 시간은 사용자 테스트가 필요합니다.

## 검증 한계

- reduced-motion 미디어 규칙이 실제 브라우저 스타일시트에 포함되어 애니메이션/전환을 제거하는 것까지 확인했습니다. 테스트 도구가 OS 모션 설정 변경을 지원하지 않아 설정을 켠 상태의 시각 비교는 하지 않았습니다.
- 저장소 오류/손상 데이터는 저장 어댑터 자동 테스트로 검증했습니다. 실제 사용자 브라우저의 저장 권한을 변경하지 않았습니다.
- Figma는 페이지 목록 확인 이후 현재 연결의 호출 한도에 걸려 상세 노드 열람을 하지 못했습니다. 지시서의 확정된 화면 흐름과 스타일을 적용했습니다.
- 개인 Cloudflare 계정에는 로그인되어 있지 않아 개인 계정 배포는 실행하지 않았습니다. 별도 체험 호스팅과 개인 Cloudflare의 영구 연결은 구분합니다.

## 출시 범위

브라우저 로컬 체험으로만 제공합니다. 서버 저장, 회원가입/로그인, 작품 공개, 자동 공개, 댓글/커뮤니티, 업로드는 구현하지 않았으며 화면에서도 작동한다고 표시하지 않습니다.
