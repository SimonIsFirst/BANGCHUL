# BANGCHUL v1.2 · Dashboard & Creative Workspace

## 기능

B(Cinematic Black)를 기본으로 유지합니다. 대시보드에는 긴 일반 텍스트를 작성·수정·비우고 이어 쓰는 편집기, 750ms 자동 저장, 실제 저장 결과/마지막 본문 수정 시각, 본문 텍스트 내려받기와 월간 기록 달력을 넣었습니다. 메인 편집기는 520px 이상이며 모바일에서는 편집기를 먼저 보여줍니다.

날짜 선택은 읽기 전용입니다. 과거 기록은 별도 영역에서만 보여주고 현재 편집기를 교체하지 않습니다. 백업/확인을 동반한 과거 복원은 이번에 넣지 않고 후속으로 분리합니다. 이전 진행 메모는 접힌 별도 영역에서 읽거나 추가할 수 있습니다.

## 데이터와 호환

저장 키 `bangchul:mvp:v1`와 `{ version: 1, draft, step, project }`는 유지합니다. 기존 데이터는 삭제·초기화하지 않습니다. 아래 필드가 없는 이전 프로젝트도 유효합니다.

```typescript
project.workspace?: { content: string; updatedAt: string };
project.history?: Record<string, { date: string; content: string; savedAt: string }>;
```

- `workspace`는 현재 본문, `history[YYYY-MM-DD]`는 로컬 날짜별 대표 저장본입니다. 부모 프로젝트에 속하므로 별도 projectId를 중복 저장하지 않습니다.
- 실제 본문 변경 시 두 필드를 하나의 localStorage 쓰기로 커밋합니다. 같은 날짜의 내용은 최종 상태로 갱신하고 다른 날짜는 유지합니다. 내용이 그대로면 저장 시각이나 활동 날짜를 바꾸지 않습니다.
- 기존 `description`과 `notes`는 독립적으로 보존합니다. 본문이 없으면 빈 편집기로 열며 설명/메모를 임의로 본문에 채우지 않습니다.
- 본문을 비운 저장도 유효한 수정이며 빈 날짜 기록으로 보존합니다. 하루 기록을 자동 저장마다 추가하지 않습니다.
- 날짜 키는 로컬 달력 날짜로 만들고 UTC 문자열의 앞 10자를 사용하지 않습니다. 손상된 본문/기록을 발견하면 조용히 덮어쓰지 않습니다.

## 저장과 안전장치

마지막 입력 750ms 후 저장하며 포커스 이탈, 문서 숨김, pagehide, beforeunload에도 동기 저장을 시도합니다. 실패하면 성공 시각을 갱신하지 않고 본문을 유지합니다. 재시도와 현재 입력의 텍스트 내려받기를 제공합니다. 저장 실패로 남은 변경이 있다면 정상 브라우저 종료 시 이탈 경고를 요청합니다. 한글 IME 조합 중에는 타이머를 미룹니다.

설명 수정과 본문 저장은 최신 프로젝트 상태를 기준으로 병합해 서로의 필드를 오래된 값으로 덮지 않게 했습니다. 초기화 후 오래된 편집기 콜백이 다른 프로젝트를 쓰지 않도록 프로젝트 ID를 검사합니다.

최대 본문은 500,000자이며 날짜별 스냅샷도 브라우저 용량을 사용합니다. 용량이 부족해도 과거 기록을 자동 삭제하지 않습니다. 기기/브라우저 간 동기화, 여러 탭의 협업/충돌 해결, 강제 종료·전원 차단 시 완전 보존은 보장하지 않습니다. 중요한 작업은 텍스트도 별도로 보관하세요. 실제 자동 공개 기능은 없고 화면에 명시합니다.

`?preview=1`은 이전처럼 메모리 전용 디자인 검토입니다. 실제로 작성·복원하려면 [일반 주소](https://bangchul-v1-preview.simonjoker19.chatgpt.site/)를 사용하세요.

## 검증과 후속

빌드와 테스트 31개가 통과했습니다. 실제 브라우저 검증은 `verification.md`에 기록했습니다. 사용자 데이터가 아닌 가상 프로젝트를 로컬 주소에서 사용했습니다. 서버/DB/결제/업로드/AI 기능은 추가하지 않았습니다.

후속은 현재 본문을 안전하게 백업하는 과거 복원, 다중 탭 충돌 방지, 실제 휴대폰 키보드·저사양 성능 확인입니다. 기존 비공개 호스팅과 개인 Cloudflare 운영 도메인은 변경하지 않습니다.
